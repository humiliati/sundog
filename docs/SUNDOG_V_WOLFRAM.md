## The thesis

> **Wolfram's observer-theory language is a good narration layer for bounded
> equivalencing, but the technical engine is elsewhere: Fisher/Halmos-Savage
> sufficiency, computational mechanics for prediction, information bottleneck
> for objective-preserving compression, and Sundog's typed act/reconstruct
> separation.**

The load-bearing distinction is:

```text
predictive sufficiency != action sufficiency != state reconstruction
```

Wolfram gestures at bounded observers extracting reducible pockets from an
irreducible substrate. Computational mechanics already makes the predictive
side rigorous: causal states are minimal sufficient statistics of the past for
future prediction. Sundog's specific move is different: a shadow can be
**state-insufficient yet control-sufficient** for a named objective.

That is the point to protect. If the note collapses "prediction", "action", and
"reconstruction" into one noun, it has failed.

## The core Sundog distinction

Let world microstate `x in X`, signature map `Phi : X -> Sigma`, signature
`sigma = Phi(x)`, objective `J`, and optimal policy `pi*`. A task is
Sundog-solvable when `pi*` is measurable with respect to the sigma-algebra
generated by `Phi`, equivalently:

```text
pi*(x) = g(Phi(x))     almost everywhere
```

for some measurable `g`.

That condition is about the **action**. It is not state reconstruction. It is
not even necessarily future prediction. It says the shadow has enough causal /
statistical access to select the optimal action for the named objective.

Regime-2 is the live cell:

```text
state reconstruction fails
control sufficiency holds
```

## Type correction: dynamic pockets are a special case

The first tempting mapping is:

```text
Wolfram pocket of reducibility ~= OrderRelative finite-order target
```

That is directionally right but type-loose. Wolfram's pockets are usually
dynamical: the observer predicts a future state or future observable without
running every underlying step. OrderRelative is target-relative: the target may
be a future observable, but it may also be a static invariant, a certificate
predicate, an algebraic degree, a cohomological period, or a surface-window
state.

So the sharpened version is:

> Wolfram's dynamical prediction pocket is one target type. Sundog generalizes
> the reducible/resisting shape to arbitrary typed targets and proves the budget
> law once:

```text
Resolves k t <-> ord t <= k
```

This is only honest with the standard guard: `ord` is axis-relative, not a
universal cross-substrate scalar.

## Roadmap: tests that would earn the distinction

These are cheap theory/toy tests before any empirical lane gets touched. The
goal is to separate prediction, action, and reconstruction as three different
equivalence relations.

| test | question | pass condition | kill condition |
| --- | --- | --- | --- |
| W0 citation-boundary lock | Can the page keep Wolfram descriptive and Crutchfield predictive? | text says computational mechanics owns prediction, not regime-2 control | any claim that epsilon-machines prove the act/reconstruct gap |
| W1 prediction-vs-action coarsening toy | Can optimal action be coarser than causal-state prediction? | two predictive states differ, but `pi*` is identical under the chosen loss | action statistic collapses only because the toy is degenerate |
| W2 action-sufficient/state-insufficient body toy | Can `Phi` act optimally while failing to reconstruct the body? | `Phi`-policy has zero/epsilon regret; reconstruction from `Phi` fails by a locked threshold | reconstruction succeeds or regret is bounded away |
| W3 objective flip falsifier | Does the shadow fail when the hidden coordinate becomes control-relevant? | changing `J` makes `Phi` insufficient | `Phi` still passes after the hidden coordinate is made necessary |
| W4 epsilon-machine neighbor test | Does computational mechanics stay in its lane? | causal states recover minimal future-prediction sufficiency; action statistic is separately compared | writeup lets predictive minimality imply control sufficiency |
| W5 OrderRelative type-generalization test | Does the same schema cover dynamic and static targets? | dynamic future-observable target and static label/certificate target both instantiate `Resolves k t` | dynamic pocket language becomes the only supported case |
| W6 information-bottleneck bridge | Does relevance-variable choice change the bottleneck? | bottleneck for `A*` can be coarser than bottleneck for `Y_future` | objective-preserving compression is treated as state reconstruction |

Preferred first implementation: W1-W3 in one deterministic finite script. It
should have exact Bayes policies, explicit fiber collisions for reconstruction
failure, and a pre-registered objective flip that kills the claim when the
hidden coordinate becomes action-relevant.

## Minimal finite toy spec

Body:

```text
B = (C, N)
```

where `C` is a small predictive/control state and `N` is high-dimensional
nuisance content. Shadow:

```text
Phi = h(C)
```

Pick an initial objective `J0` such that:

```text
pi*_J0(B) = g(Phi(B))
```

but many `B` values share the same `Phi`, so reconstruction of `B` from `Phi`
fails by construction. Then define a falsifier objective `J1` that depends on
`N`; under `J1`, no `Phi`-policy should be optimal.

Three claims must be reported separately:

1. **Prediction:** whether `Phi` is coarser/equal/finer than the causal-state
   partition for future observations.
2. **Action:** whether `Phi` is sufficient for `pi*`.
3. **Reconstruction:** whether `Phi` can recover `B`.

No single accuracy number is allowed to stand in for all three.

## Claim boundary

Will say:

- Wolfram supplies useful vocabulary for bounded observer equivalencing.
- The rigorous neighbors are computational mechanics for prediction,
  information bottleneck for relevance-preserving compression, and classical
  sufficiency for factorization.
- Sundog's distinctive cell is typed control sufficiency without state
  reconstruction.
- The first owed tests are finite, cheap, and falsifiable.

Will not say:

- Wolfram validates Sundog.
- Sundog borrows hypergraph physics, the ruliad, or atoms of space.
- Computational mechanics already proves the act/reconstruct gap.
- A statistic that predicts the future is automatically sufficient for action.
- A statistic sufficient for action reconstructs the body.
- Any "observer-relative law" exists without a named target, interface,
  filtration/order, and falsifier.

Honest current status: **framing-positive, result-unearned.** The contact point
is real enough to file, but the earned contribution depends on the W1-W3 toy
suite and any later empirical substrate obeying the same three-way split.
