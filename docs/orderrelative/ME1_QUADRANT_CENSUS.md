## 0. The verbs and filtrations (typed once, before any row)

- **σ_read(C | F):** least order of an F-statistic sufficient to *determine whether C
  holds*. Filtrations F used below: **obs** (observational), **int** (observation +
  output-slot counterfactual replay — OR-3's R), **wb** (white-box: internals; NOT part
  of the banked filtration — flagged where it matters).
- **σ_write(C):** least arity of an exogenous (node-typed, no function-rewriting)
  intervention projecting the system to C's safe point for all policies/values; the
  **price** column records what the least write costs.
- Admission requires the read-verb and the write-verb to target the *same* C.

## 2. The at-risk cell adjudication (the entry's pre-registered content)

**Claimed occupant of E∧¬M:** chat-v2 regime-2 body-resistance — "shadow
control-sufficient ∧ state-insufficient."

**The fence fires.** Typed out: the read half ("state-insufficient") has verb
*reconstruct* and object *the body state* — a value, admissible as determine-the-finest-
condition, fine. The write half ("control-sufficient") has verb *achieve a task
objective through a policy that reads the shadow* — that is neither an exogenous
intervention nor a projection to a fixed condition. **Both the verb and the object
differ from the quadrant's write coordinate.** As stated, regime-2 is a *structural
analog* (a channel sufficient for one verb, insufficient for another), not a cell
occupant.

**The salvage is exactly ME-4.** The literal write question for the model-state object
is: does an exogenous intervention *on the shadow coordinate* (activation patching along
the probe direction) project the model to the corresponding state-condition — i.e., does
downstream behavior follow the patched value? That is ME-4's probe-steer experiment,
verbatim. **Disposition: the chat-v2 cell is DEFERRED — ME-4 is its admission test.**
Two pre-registered readings of ME-4's outcomes for this census: `RESISTS` places the
stack-top state in **M∧¬E** (readable, unwritable — the model's own states join the
target channel's cell: "you can read the model's state but not write it"); `STEERS`
places it in **M∧E** (the linear rep is causally load-bearing). Either lands a
real-substrate row in the table.
